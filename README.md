# Holidaze

A website to look at venues where you can stay for the holidays. Register a user and log in to your account.

## Features

- Register account
- Log in and log out
- Browse a list of venues
- View a single venue

## Installation

### Prerequisits

- Node.js
- Git
- A code editor such as VS Code

### Install dependencies

```bash
  npm install
```

### start the app

```bash
  npm run start
```
