# Workflow repo for the CA

# Project title

## Description

A website to search for venues

## Installation

### Prerequisits

- Node.js
- Git
- A code editor such as VS Code

### Install dependencies

```bash
  npm install
```

### start watchmode

```bash
  npm run dev
```

## Features

- Register account
- Log in and log out
- Browse a list of venues
- View a single venue
